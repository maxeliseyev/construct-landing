Konstruct Messenger

Federated, post-quantum ready, minimalist hybrid messenger and email with end-to-end encryption. Seamless transition from real-time chats to asynchronous email threads. Messages wait for you, not the other way around — no intrusive notifications, just calm communication.

About

Konstruct is a modern communication platform built on openness, ultimate security, and serene user experience. It combines the instant nature of messengers with the reliability of email, using Signal-grade end-to-end encryption (Double Ratchet for forward secrecy), email-like federation (you@your-server.com), and a Zen-inspired UI without notifications, read receipts, or typing indicators.

The server is ultra-minimalist: it stores only user ID, username, and password hash — no metadata, no message content. Notifications are "blind" (just "new message arrived"), ensuring privacy even from the server. Powered by Rust for safety and performance, with a shared crypto core across platforms for consistency.

How It Works

Konstruct bridges messaging and email: send instant chats that can evolve into threaded email conversations for long-term storage. Delivery is hybrid — WebSocket for real-time when online, REST fallback with long polling, and APNs/FCM for background wake-ups on mobile.

  • Crypto Agility: Easily switch algorithms (e.g., from ECC to PQC hybrids) without rebuilding the app.
  • Self-Host Friendly: Lightweight Rust server (~100 MB RAM) runs on VPS or Raspberry Pi.
  • Privacy-First: Blind notifications, zero-knowledge proofs for auth, and minimal data storage.

Key Features

  • End-to-end encryption by default — servers see only encrypted blobs.
  • Forward secrecy — past messages stay secure even if keys leak.
  • Post-quantum readiness — hybrid X25519 + Kyber for key exchange, Ed25519 + Dilithium for signatures.
  • Federation — run your own server or use a trusted provider, with email-like addressing.
  • Lightweight server — Rust-based, minimal resource use, easy self-hosting.
  • Zen UI — no notification spam, no social noise, focus on calm interaction.
  • Hybrid Delivery — Real-time via WebSocket, fallback to REST/polling, background pushes.
