Konstruct Messenger

Federated, post-quantum ready, minimalist messenger with end-to-end encryption. Messages wait for you, not the other way around.

Federated E2EE by Default Post-Quantum Ready Minimalist

About

Konstruct is a modern messenger built on openness, security, and calm communication. It combines Signal-grade cryptography, email-like federation (you@your-server.com), and a Zen-inspired UI without notifications, read receipts, or typing indicators.

Key Features

  • End-to-end encryption by default — servers see only encrypted blobs.
  • Forward secrecy — past messages stay secure even if keys leak.
  • Post-quantum readiness — hybrid X25519 + Kyber, Ed25519 + Dilithium.
  • Federation — run your own server or use a trusted provider.
  • Lightweight server — Rust, ~100 MB RAM, Raspberry Pi friendly.
  • Zen UI — no notification spam, no social noise.
